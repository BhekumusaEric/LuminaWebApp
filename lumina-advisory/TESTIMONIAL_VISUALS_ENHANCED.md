## 🎬 Living Background Effect

### Subtle Zoom Animation:

**During Auto-Play**:
- Image slowly scales from 100% → 105%
- Takes 8 seconds (matches slide interval)
- Creates sense of movement and life
- Very subtle, not distracting

**When Paused (Hover)**:
- Image returns to 100% scale
- Smooth transition
- Static while user reads
- Resumes when user leaves

**Why This Works**:

- Professional execution
